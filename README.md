# Leblanco Store Prototype

Front-end prototype of the Leblanco WooCommerce Spec v4 (B2B healthcare tableware store, Quebec excluded).
Static site: open `index.html` or serve the folder, for example `python3 -m http.server`.

Not a live WooCommerce install. No real payments, accounts, email or storage. Demo products are flagged and can be hidden from the Prototype controls panel.
